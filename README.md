# Computer Networks Lab Work

Университетский курс по компьютерным сетям.
9 лабораторных работ в Cisco Packet Tracer + теоретические задачи.

## Применение в кибербезопасности

| Лаба | Папка | Связь с ИБ |
|------|-------|-----------|
| DHCP-сервер | [lab-01-dhcp](lab-01-dhcp/) | rogue DHCP-атаки |
| VLSM + static routing | [lab-02-vlsm](lab-02-vlsm/) | сегментация сети |
| NAPT | [lab-03-napt](lab-03-napt/) | скрытие внутренней сети |
| OSPF: параметры и отказоустойчивость | [lab-06-ospf-basic](lab-06-ospf-basic/) | OSPF spoofing, аутентификация, availability |
| OSPF: multi-access, DR/BDR | [lab-08-ospf-multiaccess](lab-08-ospf-multiaccess/) | rogue router, контроль выборов DR |
| RIPv2 | [lab-07-rip](lab-07-rip/) | уязвимости устаревших протоколов |
| Subnetting (теория) | [lab-05-subnetting-theory](subnetting-theory/) | фундамент анализа сетей |

## Структура

- `*-report.pdf` — отчёт по лабораторной
- `*-model.pkt` — модель сети в Packet Tracer

## Инструменты

Cisco Packet Tracer, CLI Cisco IOS
